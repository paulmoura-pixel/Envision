# Envision

Premium responsive Flutter experience for fitness clients and coaches.

## Included

- Image-led welcome and Apple, Google, and email entry flow
- Role-based coach and client onboarding
- Client nutrition, training, progress, coach-note, and meal logging surfaces
- Responsive coach workspace with desktop sidebar and mobile bottom navigation
- Cushion-inspired light and dark themes

## Run locally

```bash
flutter pub get
flutter run
```

The project is pinned to Flutter 3.24.5 in `.flutter-version`.
